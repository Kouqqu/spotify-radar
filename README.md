---

## ✨ Возможности

- 🔍 **Анализ музыкального вкуса**: Сверка плейлиста со свежим мировым рейтингом Топ-500 Spotify (Kworb).
- 📂 **Два удобных способа ввода**: 
  - Импорт файла `.csv` напрямую из [Exportify](https://exportify.net)
  - Быстрый текстовый ввод списка артистов
- 📊 **Детальная статистика**:
  - Точный процент мейнстрима в треклисте
  - Самый популярный артист в плейлисте и его мировое место
  - Вердикт о вкусе (от «Слушатель из параллельной вселенной» до «Завсегдатай мировых чартов»)
- 🎸 **Поиск андеграунда**: Мгновенное выделение исполнителей, находящихся вне мирового топа, с возможностью поиска по именам.
- 🎨 **Stories карточка**: Генерация стильного вертикального постера (9:16) для публикации в Instagram / Telegram с сохранением в высоком качестве.
- 🔄 **Автообновление на Android**: Встроенная проверка релизов прямо в приложении при каждом запуске.
