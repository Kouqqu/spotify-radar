## ✨ Основные возможности

- 🏆 **База чарта Top 500 Spotify (Kworb)**: точный расчет ранга каждого артиста.
- 📁 **Удобный импорт**: поддержка `.csv` файлов из [Exportify](https://exportify.net) или ручной ввод списка артистов.
- 🔍 **Умный поиск и сопоставление**: распознавание артистов с диакритикой (`Beyoncé`, `Måneskin`, `Tiësto`) и разделение совместных фитов (`feat.`, `&`, `/`).
- 📊 **Детальная статистика**:
  - Доля чарт-музыки в плейлисте (в процентах).
  - Самый популярный исполнитель с указанием его места в мире (`#rank`).
  - Раздел «Андеграунд» для независимой музыки.
- 🖼️ **Stories-карточки для соцсетей**: генерация вертикальной открытки 1080×1920 (Spotify Wrapped стиль) с твоим вердиктом и топами.

## 🛠️ Как установить приложение на Android (.apk)

1. Перейди в раздел **[Releases](https://github.com/SaaaNek/spotify-radar/releases)** и скачай файл `app-debug.apk` (или `SpotifyRadar.apk`).
2. На телефоне открой скачанный файл и нажми **«Установить»** (если система запросит разрешение на установку сторонних приложений — нажми «Разрешить»).
3. Готово! Иконка приложения появится на главном экране.
