# Spotify Top 500 Radar

Проверь, сколько твоих любимых исполнителей входят в мировой чарт Топ-500 Spotify, а сколько относится к независимому андеграунду.

[Открыть в браузере](https://kouqqu.github.io/spotify-radar/) • [Скачать для Android](https://github.com/Kouqqu/spotify-radar/releases)

---

## Что делает радар

- **Сверяет плейлист с мировым Топ-500**: импортируй `.csv` файл из [Exportify](https://exportify.net) или просто вставь список артистов вручную.
- **Считает честную статистику**: точный процент попадания в чарты, твой самый популярный артист и его текущее место в мире.
- **Находит андеграунд**: показывает редких и независимых музыкантов, которых нет в топе.
- **Делает карточку для сторис**: генерация постера с твоим вердиктом, топом артистов и статистикой в высоком качестве.
