# Spotify Top 500 Radar

Проверь, сколько твоих любимых артистов и треков входят в мировой чарт Топ-500 Spotify.

[Открыть в браузере](https://kouqqu.github.io/spotify-radar/) • [Скачать для Android (.apk)](https://github.com/Kouqqu/spotify-radar/releases)

---

## Что делает радар

- **Сверяет плейлист с мировым Топ-500 Spotify**: загрузи `.csv` файл из [Exportify](https://exportify.net) или просто введи имена исполнителей вручную.
- **Считает честную статистику**: какой процент треков из чартов, кто твой самый популярный артист и на каком он месте в мире.
- **Находит андеграунд**: показывает независимых и редких исполнителей, которых нет в мировом топе.
- **Делает карточку для сторис**: генерация вертикального постера в стиле Spotify Wrapped с твоим вердиктом и топами.

---

## Установка на Android

1. Скачай `app-debug.apk` со страницы [Releases](https://github.com/Kouqqu/spotify-radar/releases).
2. Открой файл на телефоне и подтверди установку.
